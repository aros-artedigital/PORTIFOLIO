Bem-vindo ao repositório do **Blog Aros**! Este projeto é uma plataforma web voltada para desenvolvimento, tecnologia e compartilhamento de conhecimentos dev, hospedada e gerenciada via **Netlify**.

---

- **Live Demo / Site:** [homedevweb.netlify.app](https://homedevweb.netlify.app)

---

## 🚀 Funcionalidades

- 📰 **Artigos e Postagens:** Leitura de conteúdos sobre desenvolvimento web e tecnologia.
- 📱 **Design Responsivo:** Interface adaptada para dispositivos móveis, tablets e desktops.
- ⚡ **Alta Performance:** Otimização para carregamento rápido e boa pontuação no Lighthouse.
- 🔄 **Deploy Contínuo:** Integração contínua (CI/CD) automatizada via Netlify a cada `push` na branch principal.

---

## 🛠️ Tecnologias Utilizadas

- **Front-end:** HTML5, CSS3, JavaScript / TypeScript
- **Estilização:** CSS Modules / Tailwind CSS
- **Hospedagem & CI/CD:** Netlify

## 💻 Como Rodar o Projeto Localmente

### Pré-requisitos

Certifique-se de ter o [Node.js](https://nodejs.org/) e o [Git](https://git-scm.com/) instalados em sua máquina.

### Passos para Instalação

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/seu-usuario/blog-aros.git
   ```

2. **Acesse o diretório do projeto:**
   ```bash
   cd blog-aros
   ```

3. **Instale as dependências:**
   ```bash
   npm install
   ```

4. **Inicie o servidor de desenvolvimento:**
   ```bash
   npm run dev
   ```

5. Abra o navegador em `http://localhost:3000` (ou na porta indicada no terminal).

---

## ⚙️ Deploy na Netlify

Este projeto utiliza a integração automática da Netlify com o GitHub.

1. Qualquer *push* feito para a branch `main` dispara um build automático no Netlify.
2. Para rodar o ambiente Netlify localmente (opcional), utilize a Netlify CLI:
   ```bash
   npm install netlify-cli -g
   netlify dev
   ```
